# CRUD Full Stack – Spring Boot & Angular

## Descripción

Proyecto **CRUD Full Stack** desarrollado con **Spring Boot** y **Angular**.  
En esta etapa del proyecto se ha avanzado en la **capa de persistencia y lógica de negocio**, implementando **repositorios y servicios** utilizando **Spring Data JPA**, lo que permite gestionar las operaciones CRUD sobre la base de datos MySQL.

El proyecto continúa sentando las bases para la construcción de una **API REST robusta y escalable**, preparada para su futura integración con el frontend en Angular.

## Tecnologías

- Java 17
- Spring Boot
- Spring Initializr
- Spring Data JPA
- Spring Web (REST)
- MySQL
- Maven
- Postman

## Estado del proyecto

🚧 **En desarrollo** – Implementación y prueba de endpoints REST

## Funcionalidades implementadas

- Configuración inicial del proyecto con Spring Initializr
- Conexión a base de datos MySQL
- Definición de entidades con anotaciones JPA
- Creación de **Repositorios** con Spring Data JPA
- Implementación de **Servicios** para la lógica de negocio
- Pruebas de endpoints utilizando **Postman**
- Definición de rutas base en controllers usando **@RequestMapping**
- Implementación, mejora y organización de endpoints REST (CRUD)
- Implementación de manejo de excepciones al buscar entidades en la base de datos.
- Implementación de manejo global de excepciones
- Estandarización de respuestas de error en la API REST
- Uso de códigos de error y estados HTTP personalizados
- Preparación de la API para manejo de errores avanzado y validaciones futuras
